EBNF of Alma Normalization Rules (MARC 21 / UNIMARC / CNMARC, Drools syntax)

Notation: ISO/IEC 14977 EBNF. , concatenation | alternative [ ] optional { } zero or more ( ) grouping ? ? informal description

Sources (validated 2026-10-21): - Clarivate / Ex Libris Knowledge Center, "Working with Normalization Rules", section "Normalization Rule Syntax" https://knowledge.ag-software.clarivate.com/alma/en-us/Product_Documentation/Metadata_Management/Working_with_Normalization_Rules.html#Normalization_Rule_Syntax - Ex Libris Developer Network, "Alma Normalization Rule Examples" https://developers.exlibrisgroup.com/blog/alma-normalization-rule-examples/

Whitespace (spaces, tabs, new lines) and comments may appear between any two tokens and are not repeated in every production below. Inside a quoted string whitespace is significant.

=====================================================================

Rule file

=====================================================================

A rule file contains one or more rules. When several rules touch the same fields, give them a priority: rules with a higher priority run first.

rule_file

rule_file = { rule }- ;

rule_file is referencing:

  • rule

a single normalization rule: a name, an optional priority, one record level condition (when) and one or more actions (then) applied in order. when must be the only word on its line; the condition goes on the next line.

rule

rule = "rule" , rule_name , [ priority_clause ] , "when" , when_condition , "then" , { action }- , "end" ;

Items referencing rule:

  • rule_file

rule is referencing:

  • rule_name
  • priority_clause
  • when_condition
  • action

a short description of what the rule does. At most 255 characters, no backslash, no "$$".

rule_name

rule_name = dq_string ;

Items referencing rule_name:

  • rule

rule_name is referencing:

  • dq_string

priority and salience are synonyms. Higher runs first: 2 runs before 1, 10 runs before 9. Omitted means the default priority. Only needed when several rules work on the same fields; otherwise rules run top to bottom.

priority_clause

priority_clause = ( "priority" | "salience" ) , integer ;

Items referencing priority_clause:

  • rule

priority_clause is referencing:

  • integer
